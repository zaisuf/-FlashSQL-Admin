# -FlashSQL-Admin

Flash SQL Studio — a multi-database SQL workspace (PostgreSQL, MySQL / MariaDB, SQL Server, SQLite).

## Features

- Database explorer with schema/table browsing and inline cell editing
- SQL editor ("Flash SQL Studio") with table/column autocomplete, multi-statement runs, selection run, and cancel
- Data preview grid with search, sort and pagination
- Session persistence with one-click reconnect

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000
